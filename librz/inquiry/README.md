# RzInquiry

This module implements novel analysis approaches based on RzIL. It is meant as
an intermediate ground to implement and evaluate new ideas before eventually
moving them to their respective final modules, like RzAnalysis.
Thus, everything in this module should be considered experimental and subject
to change.
